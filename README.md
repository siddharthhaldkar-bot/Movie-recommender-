# Movie-recommender-
A content-based movie recommendation system built using the **TMDB 5000 Movie Dataset**. The system suggests movies similar to a user's selection based on metadata such as plot summaries, genres, keywords, cast, and crew.

Movie recommender from scratch by cleaning raw data to workable data using pandas and then using scikitlearn library for the recommendation.
Here is the links for dataset
https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata
